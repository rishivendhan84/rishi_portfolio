# github-resources: curated AI and ML repo index

## What it is

A public, curated index of 170 real GitHub projects across 16 domains (AI agents, LLMs and RAG, generative AI, computer vision, NLP, MLOps, full-stack, security and more), plus a teardown log. Each day an automated scan pulled GitHub trending and a rising-repo search, kept the top 3 repos and 1 public knowledge vault, gave each a 10-minute triage and one of four verdicts (teardown, toolbox, vault-study, dropped), and published the log to the repo. Released under CC0.

## Status

The daily teardown scan ran from July 21 to August 30, 2026 and is currently paused. The index itself remains available.

## Tip from the repo

Swapping github.com for gitingest.com in any repo URL returns the whole repository as one text blob, ready to paste into an LLM for a first-pass explanation.
